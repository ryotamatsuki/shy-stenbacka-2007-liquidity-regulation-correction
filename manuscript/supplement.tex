\section*{S1. Verification architecture}
The accompanying repository contains three independent verification layers. The production symbolic script reconstructs the reduced profit objective from the market-share and cutoff identities and differentiates it with SymPy. A second implementation uses Python's exact rational arithmetic and exact Simpson evaluation of the quadratic risky-profit integrand; it does not import the symbolic derivative. A Lean~4/mathlib project certifies the proof-critical algebraic identities and selected sign claims.

\section*{S2. Exact regression witness}
At
\[
\delta=\tfrac12,\quad \rho=0,\quad v=1,\quad r=\tfrac12,\quad
\tau=1,\quad \theta_A=\theta_B=0,
\]
the source candidate is $i_A=i_B=-1$. Direct differentiation of the reconstructed reduced objective gives
\[
\left.\frac{\partial\pi_A}{\partial i_A}\right|_{(-1,-1)}=\frac5{96}>0.
\]
The corrected symmetric stationary rate is $-3/4$. The finite deviation $i_A=-99/100$ raises profit by exactly $1/2000$, while $x_R(\lambda)=101/200-\lambda/200$ and $x_L=201/400$ remain strictly between zero and one.
